Dequantizer
===========

Converts integer clusters to ``float32`` clusters for eta and interpolation,
optionally applying a gain in the same pass.

.. code:: python

    from aare import ClusterFile, Dequantizer, calculate_eta2

    dequantizer = Dequantizer(gain=gain_map, seed=1)
    with ClusterFile("path/to/file") as f:
        for chunk in f.chunks(1_000_000):
            clusters = dequantizer(chunk)
            eta = calculate_eta2(clusters)

``truncated`` states how the writer of the clusters converted pixel values to
integers, which decides the interval each value is drawn from:

- ``truncated=False`` (default): for cluster files generated by aare, which
  rounds to the nearest integer. ``n`` is spread over ``[n - 0.5, n + 0.5)``.
- ``truncated=True``: for old cluster files, which were truncated toward
  zero. Positive ``n`` is spread over ``[n, n + 1)``, negative ``n`` over
  ``(n - 1, n]`` and 0 over ``(-1, 1)``.

In a truncated file the pixel value 0 occurs about twice as often as 1 or -1:

.. code:: python

    data = np.array(chunk)["data"]
    np.bincount(data[(data >= -3) & (data <= 3)] + 3)
